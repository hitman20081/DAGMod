Files affected:
  - data/dagmod/loot_table/boss/boss_loot_table.json

The tag #minecraft:in_enchanting_table was removed in MC 1.21. Books rolled

--- 1B. DeathGraveMixin - keepInventory never suppresses graves ---

File: src/main/java/com/github/hitman20081/dagmod/mixin/DeathGraveMixin.java
Line: 36

world.getGameRules().get(GameRules.KEEP_INVENTORY) returns a BooleanValue
object, not a boolean. The condition is always true, so graves never suppress
when keepInventory is enabled.
Fix: change .get() to .getBoolean()

[ ] Code fix applied
[ ] Enable keepInventory gamerule (/gamerule keepInventory true)
[ ] Die (fall damage, void, etc.)
[ ] Verify NO grave spawns and items stay in inventory
[ ] Disable keepInventory and die again
[ ] Verify grave DOES spawn with items inside
    >

--- 1C. MageStatusEffectMixin - targets removed single-arg addEffect overload ---

File: src/main/java/com/github/hitman20081/dagmod/mixin/MageStatusEffectMixin.java

Targets addEffect(MobEffectInstance) single-arg overload. In MC 1.21+ the
primary overload is addEffect(MobEffectInstance, Entity). With defaultRequire=1
in the mixin config, if the old overload is gone this will CRASH ON LOAD.

[ ] Verify game loads without crash on startup
[ ] If it crashes - mixin needs to target the two-arg overload
[ ] Select Mage class
[ ] Drink a potion (e.g. Strength or Regeneration)
[ ] Verify the effect duration is extended compared to a non-Mage character
